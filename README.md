# Appare! レーダー

チェキ会で話すネタを探すための非公式 Appare! ファンサイトです。9人の趣味や本人の投稿に出典を付け、質問例と映画・音楽・お店などの寄り道を掲載しています。

公開先: https://miiifa.github.io/appare-radar/

## 毎朝の更新

`.github/workflows/daily-update.yml` が毎日 09:00 JST に `scripts/update_site.py` を実行します。公式スケジュールの近日予定と FM FUJI の Appare! 投稿一覧を取得し、`index.html` の `AUTO_EVENTS` と `AUTO_POSTS` の範囲だけを置き換え、変更があればコミットして GitHub Pages に公開します。GitHub の定期実行は開始時刻に遅れる場合があります。Actions の `workflow_dispatch` から手動実行もできます。

取得や解析に失敗した項目は最後に掲載したカードを維持します。その日はエラーで処理を止め、Actions に失敗を表示します。期限の過ぎた予定・期間限定の寄り道は、サイト閲覧時にも日本時間で非表示になります。

ラジオ番組の投稿が止まった場合は、最終投稿の日付と過去の投稿を明記します。取得した投稿本文から好みを自動推測しません。メンバーの趣味・本人の言葉を要約したカードと、ゆかりの場所や商品の選定は出典を見て手作業で編集してください。

## ローカルでの確認

`python scripts/update_site.py` で取得結果を確認できます。Python 3.12 の標準ライブラリだけを使用します。外部サイトへ接続できる環境で実行してください。
